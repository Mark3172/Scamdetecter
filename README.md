# Scam Message Detection API

Proof-of-concept service that classifies SMS / chat-style messages as **Legitimate** or **Scam**. Text is cleaned with NLTK, vectorized with TF-IDF, and scored by a Random Forest.

Phase 2 added a scan console, contributing phrases, and batch screening. Phase 3 adds in-message highlights, rule-based cues, right/wrong feedback, CSV export, and a Review tab with in-sample model stats.

This is a demonstration model trained on a small mock corpus. It is not production fraud detection.

## Stack

- Python 3.10+
- FastAPI + Uvicorn
- scikit-learn (`TfidfVectorizer` + `RandomForestClassifier`)
- NLTK (English stopwords)
- joblib (model persistence)

## Project layout

| File | Role |
| --- | --- |
| `preprocessing.py` | Lowercasing, URL placeholder, stopword removal |
| `train.py` | Mock dataset, sklearn pipeline, writes `scam_detector.joblib` |
| `classifier.py` | Inference, probabilities, cues, highlights |
| `feedback.py` | JSONL store for right/wrong marks |
| `main.py` | FastAPI app, JSON API, CSV export, and web UI |
| `static/` | Scan console (single, batch, review) |
| `scam_detector.joblib` | Trained pipeline (generated by `train.py`) |

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Train

```bash
python train.py
```

That downloads NLTK stopwords if needed, trains on the mock messages in `train.py`, prints a small holdout report, and saves `scam_detector.joblib`.

## Run

```bash
uvicorn main:app --host 0.0.0.0 --port 8765 --reload
```

## Detect a message

```bash
curl -s -X POST http://127.0.0.1:8765/api/v1/detect \
  -H "Content-Type: application/json" \
  -d '{"text": "URGENT: Your bank account has been locked. Verify immediately at http://secure-bank-login.com"}'
```

The response still includes `original_text`, `prediction`, and `confidence_score`, plus:

- `scam_probability` — probability of the Scam class
- `signals` — phrases in the message with the highest TF-IDF × forest importance
- `cues` — rule-based flags (link, urgency, money, verify/login)
- `highlights` — character spans to mark in the original text
- `advice` — a short next-step warning

Batch and CSV:

```bash
curl -s -X POST http://127.0.0.1:8765/api/v1/detect/batch \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"text":"Claim your free gift card http://prize-win.com"},{"text":"See you at the gym tomorrow"}]}'

curl -s -X POST http://127.0.0.1:8765/api/v1/detect/batch.csv \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"text":"Claim your free gift card http://prize-win.com"}]}' \
  -o scam-scan.csv
```

Feedback:

```bash
curl -s -X POST http://127.0.0.1:8765/api/v1/feedback \
  -H "Content-Type: application/json" \
  -d '{"text":"Hey, are we still on for dinner at 7 tonight?","predicted":"Legitimate","actual":"Legitimate"}'
```

## Error handling

- Empty / whitespace `text` → HTTP 422
- Missing `scam_detector.joblib` → API starts, `/health` reports `model_unavailable`, detect endpoints return HTTP 503
- Inference failures → HTTP 500
