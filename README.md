# Scam Message Detection API

Proof-of-concept REST API that classifies SMS / chat-style messages as **Legitimate** or **Scam**. Text is cleaned with NLTK, vectorized with TF-IDF, and scored by a Random Forest classifier.

This is a demonstration model trained on a small mock corpus. It is not production fraud detection.

## Stack

- Python 3.10+
- FastAPI + Uvicorn
- scikit-learn (`TfidfVectorizer` + `RandomForestClassifier`)
- NLTK (English stopwords)
- joblib (model persistence)

## Project layout

| File | Role |
| --- | --- |
| `preprocessing.py` | Lowercasing, URL/punctuation stripping, stopword removal |
| `train.py` | Mock dataset, sklearn pipeline, writes `scam_detector.joblib` |
| `main.py` | FastAPI app and `POST /api/v1/detect` |
| `scam_detector.joblib` | Trained pipeline (generated by `train.py`) |

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Train

```bash
python train.py
```

That downloads NLTK stopwords if needed, trains on the mock messages in `train.py`, prints a small holdout report, and saves `scam_detector.joblib`.

## Run the API

```bash
uvicorn main:app --host 0.0.0.0 --port 8765 --reload
```

- Service info: [http://127.0.0.1:8765/](http://127.0.0.1:8765/)
- Swagger UI: [http://127.0.0.1:8765/docs](http://127.0.0.1:8765/docs)
- Health: [http://127.0.0.1:8765/health](http://127.0.0.1:8765/health)

## Detect a message

```bash
curl -s -X POST http://127.0.0.1:8765/api/v1/detect \
  -H "Content-Type: application/json" \
  -d '{"text": "URGENT: Your bank account has been locked. Verify immediately at http://secure-bank-login.com"}'
```

Example response:

```json
{
  "original_text": "URGENT: Your bank account has been locked. Verify immediately at http://secure-bank-login.com",
  "prediction": "Scam",
  "confidence_score": 0.91
}
```

`confidence_score` is the Random Forest probability of the predicted class.

## Error handling

- Empty / whitespace `text` → HTTP 422
- Missing `scam_detector.joblib` → API starts, `/health` reports `model_unavailable`, `/api/v1/detect` returns HTTP 503
- Inference failures → HTTP 500
